# Al-Jabal e-Library | مكتبة الجبل

A responsive Arabic e-library website built with HTML, CSS, JavaScript and TypeScript.

## Pages

- **Home:** welcome section and featured books
- **Books:** all books with search and category filter
- **Book details:** shows each book's info using its id from the URL
- **About:** library info with a sections table
- **Contact:** contact form with validation

## Technologies

- HTML5 (semantic tags, forms, tables, RTL)
- CSS3 (Flexbox, Grid, CSS variables, Media Queries)
- JavaScript (DOM, events, filter, find, URLSearchParams)
- TypeScript (interfaces and types)

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/Moayad0076/e-library.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
